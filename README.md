# Marina Fuel Nexus Explorer

Interactive dashboard for the Cyprus marinas water–energy–emissions–land nexus studies (Alamanos & Nisiforou, 2027).

`index.html` is fully self-contained (data, map and charts included) and runs offline.

## Publish with GitHub Pages
1. Upload `index.html` and `.nojekyll` to the root of this repository (main branch).
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
3. After ~1 minute the site is live at https://alamanos11.github.io/Marina-Nexus-Explorer/

Scope: recreational marinas and yacht fuel only; island-wide figures are context, not a national assessment.
